FAQs

Is Forkly a real food delivery service?

No. Forkly is a portfolio project that shows what a complete food ordering app can look like. The restaurants and dishes are sample data.

Which devices does it run on?

It’s built with React Native, so one codebase runs on Android, iOS and the web. Right now you can try the web version or install the Android app.

Where is my information stored?

Your account, cart, orders and reservations are saved on your own device. Nothing is sent to a server.

Does booking a table hold a table for me?

No. A reservation just tells the restaurant when you plan to come, so they’re expecting you.
